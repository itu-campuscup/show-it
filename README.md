# Show IT ⚓

A mobile-first spectator frontend for CampusCup. It deliberately does **not** call Judge IT or Convex directly.

## Pages

- `/drink` — current heat Beer leaderboard
- `/spin` — current heat Spin RPM leaderboard
- `/sail` — current heat Sail leaderboard

The app reads static JSON generated by [`itu-campuscup/judge-it-stats`](https://github.com/itu-campuscup/judge-it-stats). GitHub Pages absorbs spectator traffic. The stats generator publishes every five minutes, so Show IT refreshes its published data once per minute without touching Judge IT.

## Data source

By default the app uses:

`https://itu-campuscup.github.io/judge-it-stats`

Override with `NEXT_PUBLIC_STATS_BASE_URL` when testing another generated stats site.

**Current blocker:** the default stats Pages URL returned 404 on 2026-08-23. Enable GitHub Pages in `itu-campuscup/judge-it-stats` with **Source: GitHub Actions**, then run its `Generate Stats` workflow once. Its existing output already provides completed per-heat Beer/Spin/Sail rankings.

## Deploy Show IT

This repository has a GitHub Pages workflow. In the repository settings, enable **Pages → Source: GitHub Actions**. Every push to `main` then builds the static Next export from `out/`.

## Local development

```bash
bun install --backend copyfile
bun dev
```

On Android/Termux, build with Webpack because Turbopack lacks Android/ARM64 support:

```bash
node node_modules/next/dist/bin/next build --webpack
```
